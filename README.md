# Dean & Director KRC – 60-Mark Working Assessment Matrix

A bilingual English/Marathi, browser-based assessment-support site for two post selections:
- Dean (default selection)
- Director, Knowledge Resource Centre (KRC)

## Included
- Exactly two post options in the dropdown.
- 60-mark Academic & Research working matrix only.
- A, B and C subtotals and an overall total out of 60.
- University-category weightage selectors and combined M.Phil. + Ph.D. ceiling.
- Bottom reference note with links to the Government Resolution, relevant University Directions and advertisements.
- Print / Save as PDF.
- No backend or external JavaScript libraries.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and this `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Important applicability note
The 11.02.2026 Government Resolution gives cadre-specific assessment for regular teacher recruitment; it does not prescribe a separate 60-mark matrix for Dean or Director KRC. Dean is a separate statutory officer post. The KRC Direction refers to Director KRC within the teacher definition and Section 102, but does not provide a KRC-specific 60-mark schedule. Therefore, the matrix displayed is a provisional working/reference matrix and must not be treated as an approved selection scheme unless confirmed/adopted by the competent University authority. Check eligibility, experience and selection-committee provisions separately against each Direction and advertisement.
